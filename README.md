# keasproject — сайт-визитка

Личная страница-визитка: проекты, ссылки для поддержки, контакты.

## Стек

Один файл `index.html` — без зависимостей, сборки и внешних шрифтов.
Material Design 3, тёмная тема с оранжевым акцентом, строгая сетка
(без градиентов, теней и анимаций).

## Разделы

- **Обо мне** — короткий текст о себе (пока заглушка, заполняется в `index.html`, секция `#about`)
- **Проекты** — карточки репозиториев (сейчас: kizboot, kizQR)
- **Поддержать** — Dalink, YooMoney
- **Контакты** — Telegram-канал, GitHub

## Как посмотреть

Просто открыть `index.html` в браузере.

## Публикация

Для GitHub Pages: Settings → Pages → Source: `main`, корень (`/`).
Сайт будет доступен по адресу `https://keasring.github.io/keasproject/`.
